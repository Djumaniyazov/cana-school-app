# CANA School — веб-портал школы

Рабочий портал школы: директор, администратор, преподаватель, ученик, родитель
и охрана. Работает на той же базе, что и мобильное приложение, — одни учётные
записи, роли и данные.

Вход по email и паролю; аккаунты создаёт администратор школы. Тот же логин
работает в мобильном приложении.

Это статическая сборка портала; исходный код платформы хранится отдельно.
Демо на синтетических данных — в отдельном репозитории `cana-school-demo`.
